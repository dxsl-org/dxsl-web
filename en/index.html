OPERATING SYSTEM

Cellos

Next-Gen Operating System

A high-security, microkernel-based operating system engineered for minimal attack surface, optimal memory footprint, hardware independence, and absolute zero telemetry.

  • Microkernel / Hybrid secure process isolation
  • Zero telemetry & strict hardware privacy
  • Multi-architecture: x86_64, ARM, RISC-V
  • Predictable memory management & ultra-fast boot
Status: Research / Alpha Source & Specs
INPUT METHOD

Buttre

Modern Vietnamese IME

Lightweight, ergonomic, modern Vietnamese input engine tailored for developers and power users. Solves cursor-jump bugs and terminal key-swallowing natively.

  • Zero keylogging & strictly local keystroke parsing
  • Full Telex, VNI, and Simple Telex engines
  • Glitch-free inside code editors, CLI & terminals
  • Cross-platform: Linux, Windows, macOS, Web
Status: Stable Release v1.x Downloads & Docs
AI ASSISTANT

Haily

Personal AI Companion

A privacy-centric personal AI assistant running on local hardware or private instances. Accelerates research workflows, coding, task automation, and private knowledge synthesis.

  • Local-first architecture & sovereign offline mode
  • Zero commercial training on personal interactions
  • Modular skill system & extensible protocol tools
  • Context engineering & autonomous task capability
Status: Beta Preview Explore Haily
// RESEARCH & DIGITAL TRANSFORMATION

Human-Centric Research, Practical Impact

True digital transformation is not about buying proprietary software subscriptions. At DXSL, we build sovereign, open infrastructure enabling organizations to operate transparently without predatory vendor lock-in.

◆ Open Digital Infrastructure

Designing decentralized storage networks, self-hosted operational backbones, and zero-trust security profiles for civic and educational institutions.

◆ Edge AI & Private Cognitive Models

Benchmarking Small Language Models (SLMs) and efficient quantizations to run high-utility tasks on commodity consumer hardware without external data leakage.

◆ FOSS Toolkits for Public Education & NGOs

Delivering turn-key, zero-licensing digital toolkits for community libraries, schools, and non-profits that lack enterprise IT budgets.
